This experiment deliberately reads ONLY /filtered_imu_xsens (actual angular_velocity.z and source header times) and /camera/color/image_raw/compressed (source image content and times). It does not even access /Darknav/pose or PX4 odometry payloads, preventing ground-truth leakage. Select first image center-column x=floor(width/2), convert the original image to grayscale, split into 16 vertical bands and threshold each average at 128 to form a deterministic conventional 16-bit fingerprint. No latent ML, training on later images, feature tuning or privileged ground truth used. Integrate angular_velocity.z trapezoidally using past-known IMU data, extrapolate from last gyro sample at most 20ms to frame timestamp; no future gyroscope samples consulted, and only source-header stamps accepted. Define map phase relative to first eligible camera frame and freeze at earliest apparent absolute +/- 360° integrated yaw; if no complete turn, report partial. For multiple images in a nominal 64bin cell, report Hamming differences >2 and quarantine under a declared 2bit *diagnostic threshold*, not a physically calibrated noise guarantee. Never grant source-warrant C99 flag or navigation permission.

The same real image and IMU clock could be offset, the IMU frame may differ from camera frame, and gyro biases and phase uncertainty have no verified physical bound. The measured 600 frames are a regular RGB camera, not a 1-pixel line camera; the selected one-column reading tests only informational sparsity. No genuine later-turn relocalization/flight readiness is demonstrated. Distinguish source-access success and offline diagnostic map feasibility from mathematically authorized gyro reference map or navigation claim.
