# MathGraph observation-window compiler — source-authentic EvSLAM first-turn requirements

This is an **offline consequence-to-observation feasibility compiler**, not a visual compass and not an autonomous acquisition controller. It takes an independently published real drone reference trajectory, 64 target angular bins, a hypothetical clock uncertainty and an ideal uniform camera sampling cadence. It derives which missing angular observations could in principle be captured with provable one-bin time-phase support within the declared **piecewise-linear 10-Hz source-pose model**.

**Mathematics.** Freeze the first *source-projected* full 2π body-Y turn, without borrowing any future revolution. Construct the exact time preimages of all 64 half-open angular bins for the continuous, piecewise-linear interpolant of the source reference orientation. Explicitly split at every GT pose knot and every bin-boundary crossing; no monotone-clipping of motion reversals. For each connected preimage (a,b), the conservative clock interval of halfwidth d remains in that bin for camera-center times in (a+d,b-d). Each bin's longest such open window is the available source-conditional observation slot. If a bin has no positive slot, return BOUNDED_MISSING_SOURCE_PHASE_WINDOWS; if source motion fails to cross the first 2π, BOUNDED_NO_FIRST_COMPLETE_TURN.

For an *ideal periodic camera sampler* with unknown phase offset and cadence h, every nonempty slot of width STRICTLY GREATER THAN h necessarily receives a sample. Thus the minimum strictly sufficient ideal sample rate is floor(1/minimum-slot-width)+1, if and only if all 64 source bins have positive windows. The result also separately gives guaranteed available-bin counts for 10,20,25,30,40,50,100,400 Hz and the largest hypothetical clock halfwidth at which all 64 have some source-model time slot. These rates are not flight/hardware certifications, because actual event cameras can yield no usable events inside a nominal time slot.

**Authority boundaries.** No raw EvSLAM camera events or IMU samples were acquired (the original 6.10/6.55 GB bags are blocked by Google quota). The compiler's GT-selected slot midpoints are an OFFLINE retrospective oracle and MUST NEVER be fed to the online estimator. Calibration's signed nominal shift is only an illustrative sensitivity halfwidth: without authentic clock-error witnesses, a permissioned real first-turn capture remains UNKNOWN. Pose motion between 100-ms source samples is unbounded physically, so the exact finite interpolation is NOT an actual dynamics certificate. Even if all bins are ideally time-sampleable, single-column events may be absent; scene appearance, parallax, gyro bias and corrected heading remain UNKNOWN. An equally informed conventional sampler can use the same source feasibility calculation; no unique MathGraph advantage.
