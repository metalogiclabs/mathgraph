# TOPSPIN original real event-column acquisition — v0 (separate observational transfer)

**Object/source:** Ethan Elms et al., [Zenodo TOPSPIN v1](https://zenodo.org/records/10884694). Author metadata states a **stationary event camera observing a rotating object on a turntable**, NOT a continuously spinning airborne camera. The archive carries event timestamps and camera geometry but no gyro or external absolute heading ground truth. Even a visually recurring signal cannot be promoted to flight compass accuracy. Selection is for low bandwidth, before opening source content.

**Pre-source freeze:** pick the smallest authors' slow perpendicular source `hubble-perpendicular-slow.tar.gz` (published MD5 `791716392f201526d814267155291147`, 24.4 MB) for development; reserve `switch-perpendicular-slow.tar.gz` (MD5 `498aa6f860bd226384a60c773ee8a8a9`, 28.3 MB) for later source-distinct prospective transfer only after freezing descriptor/matcher parameters on the first object.

**Preflight only:** acquire original archive and check published MD5 before interpretation; generate new SHA256 receipt; require exactly one event CSV and camera meta.json, reject traversal/link archives; preselect x = floor(camera width/2) from meta.json BEFORE reading events. Scan original CSV linearly, retain all timestamps and count valid center-column events and nonempty 50-ms windows. Require >=2000 center events, >=100 nonempty windows and in-order event timestamps to advance to an actual periodic-appearance method. A match is NOT built here, and no number of object revolutions is assumed from elapsed time or event count. Missing files/format/geometry, source drift and low coverage return UNKNOWN/REJECTED, not manufactured data.

**Boundary:** The result can only inform whether a thin event column carries physically recorded moving-object texture. No true gyro, turn-count truth, first-turn phase reference or independent heading accuracy; no claim of MathGraph advantage. This real-source transfer is separate from the UZH/ECRot and EFRD drone-equivalence qualification chains. No Joshua repository or PR is modified.
