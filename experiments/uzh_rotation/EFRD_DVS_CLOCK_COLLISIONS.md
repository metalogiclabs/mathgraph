# EFRD original camera IMU: exact repeated-header source-fidelity audit

The v1 real-source timing job [Actions 39879643616](https://github.com/metalogiclabs/mathgraph/actions/runs/39879643616) independently found 16 duplicated header timestamps among 61,279 camera IMU readings, but did not determine whether those were original-byte-identical retransmissions. It correctly refused to fit that stream. The separate /imu/data stream has 0 duplicates and showed weak within-exposed-lab1 rate correlation (training 0.1116, validation 0.1280 at 25ms, versus 0.1119 at zero lag); timing advantage NOT WARRANTED.

This source-fidelity experiment verifies the SHA256 of the original lab1 2,956,823,690 byte bag before loading data. Read each original camera-IMU message together with its exact nanosecond source-header time, bag-receipt timestamp, original wire bytes, and three-axis angular velocity. Preserve all repeated-header observations. An exact retransmission is one whose original bytes AND receipt timestamp both match; all other repeated timestamp records are explicitly conflicting or unresolved. Never select the record that best matches external motion capture.

For a retrospective diagnostic only, compute two deterministic readings per unique timestamp: minimum and maximum measured gyro-vector magnitude among the actually recorded alternatives. Run the same frozen ±200ms, 5ms-grid first-half fitting and second-half validation on both source-allowed curves and compare both to the same zero-lag baseline. **These two curves are NOT exhaustive Pearson-correlation bounds and NOT physical IMU error bounds.** The source can remain UNKNOWN even if both agree. This experiment may not authorize a navigation correction, establish absolute heading accuracy, or imply EFRD completed panoramic turns. Unread camera-event stream and external lab2 values remain out of scope.

Negative controls include identical retransmissions, different raw readings, altered receipt timestamps, reverse times, triple-collision preservation and nonfinite rates. Preserve failures; retain all source bytes externally, not in MathGraph git.
