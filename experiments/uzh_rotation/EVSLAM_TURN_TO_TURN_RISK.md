# EvSLAM real multi-revolution revisit-geometry residual

Two original published FPV drone GT sequences independently qualify 3.99 and 6.00 longest uninterrupted projected body-Y turns: [qualification Actions 39933938407](https://github.com/metalogiclabs/mathgraph/actions/runs/39933938407), code commit 610a0827. They also exhibit ~13m and ~12.5m total translational path. The raw bags (6.10GB and 6.55GB per publisher Drive metadata) are quota-blocked; both source-access attempts are preserved at [Actions 39934255115](https://github.com/metalogiclabs/mathgraph/actions/runs/39934255115) and [39934784749](https://github.com/metalogiclabs/mathgraph/actions/runs/39934784749). The latter independently identified publisher quota obstruction with an explicit UNKNOWN artifact, not missing camera data hidden behind a green run.

Next cheapest test: quantitative physically changed location and orientation at angularly corresponding poses across the drone's turns. This is retrospective offline dataset *suitability*, NOT a visual recurrence, gyro or navigation experiment. Use same original four Git-blob-pinned GT/reference files, compute relative quaternion body-Y incremental rotation, choose orientation sign only from source GT to define positive projected phase (evaluation only), and compare each of 16 angular bins from turn 0 against each later complete projected turn. Interpolate poses only between actual adjacent crossing samples. If phase reverses, never force monotonicity. Report median/p90/max translation, true 3D orientation difference and number of matched bins. An equally informed conventional observer has exactly the same offline GT, so no MathGraph advantage. No source GT is supplied to the visual estimator or its confidence decisions.

Even an exact same-phase pose need not have same visual appearance due to dynamic objects or lighting; and translation difference is a potential parallax obstruction, not proof of observed visual mismatch without sensor events and scene depth. Do not claim camera/gyro synchronization, physical single-line camera, flight suitability or source-autonomous navigation from these results.
