# MathGraph fine-C99 source-bound map admission: publisher-referenced precision test

The existing 146-byte C99 reference map `finite_partial_map.c/.h` and original 1,024-tick source-bound adapter `firstturn_interval_capture.c/.h` remain **byte-identical**. The new independent `firstturn_fine_capture.c/.h` provides a 65,536-tick angular phase with the same 64 map bins (1,024 fine ticks each), **no extra persistent map memory**, and identical fail-closed semantics: authorize capture only when the inclusive externally warranted phase interval fits inside a single bin. If the radius >=512 ticks, all samples are ambiguous. Map authority and permission tracking are unchanged.

**Independent finite oracle:** test all 65,536 phases across 11 radii (0,1,2,3,8,32,128,256,511,512,1023): 720,896 configurations. Oracle computes whether `r <= offset <= 1023-r` from phase offset within its bin, independently of the C code's wrap interval endpoints. Separate controls explicitly enumerate all permissible physical phase shifts near boundaries, test frozen maps, exact edges, false-error bounds and adversarial source violations. Existing older 8,192 coarse-oracle controls also rerun. Passing proves the finite fixed-point interval rule only, not physical sensor safety.

**Original-source experiment:** [EvSLAM calibration phase-source CI 40018662404](https://github.com/metalogiclabs/mathgraph/actions/runs/40018662404) authenticated original publisher camera calibration `2aee1692299ae519251e921c087503263e187a3e79cf6c341a31b97bd87a2b72`, IMU calibration `561da3630bce3f7dfd27b7ad134441f5053abaccadfa9cb89771ae8493ac051a`, and original GT `drone_rot_norm`/`drone_rot_fast` trajectories. It found three and one ambiguous first-turn **POSE** samples under the declared hypothetical ±2.585987786-ms interval, while the 1,024-tick guard refused 22 and 26 samples, respectively. These are 10Hz published GT poses, NOT observed camera/IMU ticks. The nominal publisher timeshift is NOT a certified error radius. New replay uses the identical original source and identical hypothetical error set for BOTH guard policies, converts phase with a +1 tick fractional-quantization cushion and compares C-native map admissions to independent continuous source-pose bounds. An equally informed conventional guard can use the same precision.

**Promotion boundary:** Any recovered admissions demonstrate better numeric precision and availability conditional on the **hypothetical** time interval and 100ms piecewise-linear GT model. They do NOT establish physical gyro source integrity, onboard correction error, camera map coverage, sensor power, real-world line-camera flight or a unique MathGraph safety/performance advantage.
