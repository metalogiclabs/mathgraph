# UZH DAVIS shapes_rotation: authentic continuous-spin suitability screen

The UZH Robotics and Perception Group publishes source [shapes_rotation.zip](https://files.ifi.uzh.ch/rpg/datasets/davis/shapes_rotation.zip), ~150 MB, containing DAVIS 240C original `events.txt`, `imu.txt`, `groundtruth.txt`, `calib.txt`. The source is an independent 2016-era real motion-capture/event/gyro source, **not** a drone. `poster_rotation` and `boxes_rotation` in earlier MathGraph research never qualified multiple full yaw turns; their prior results remain controlling for those sources. `shapes_rotation` has not been admitted or rejected by those unrelated sequences.

**FROZEN screening method before source reading:** download and SHA256 the original archive; reject ZipSlip/link-like paths, inspect only `groundtruth.txt` (timestamp px py pz qx qy qz qw) and file name/size metadata. No camera event or IMU value is opened. Validate 100+ original monotone, near-unit quaternion poses and use nearest original GT pose to every fixed 50ms source-time gridpoint. This 20Hz predeclared downsample reduces ultra-small apparent 200Hz mocap direction reversals; no interpolation through missing poses is permitted. Relative camera-frame SO(3) quaternion logarithms are computed independently via SciPy and a manual quaternion implementation (source `evslam_reference_turns.independent_rotvecs`) and must agree. Compute all three body-frame x/y/z axes, requiring a longest signed continuous projected run >=2.0 turns AND >=90% of total 3D angular travel along that axis. Exclude any >0.1s sampled gap or >=90deg relative step; distinguish cumulative absolute travel from continuous directional turning.

**Promotion rule:** If any predeclared axis passes, only label `CANDIDATE_FOR_SEPARATE_REAL_EVENT_IMU_REPLAY`. If no axis passes, `REJECTED_AS_CONTINUOUS_2_TURN_DATASET_IN_DECLARED_MODEL`. Never change the method against this exposed source; for a subsequent prospective test freeze a different dataset and algorithm first. Actual raw one-column event map, calibrated camera/IMU time, heading correction, ground-truth reuse and relative visual navigation advantage remain NOT TESTED. Joshua's upstream repositories remain untouched.
