# MathGraph source-evidence-gated first-turn acquisition obligation (C99)

This is a **small offline-tested, deployable-shaped acquisition controller**, NOT independent physical clock calibration or a flown visual compass. It complements the source-observation-window compiler (Actions #40025428489) and the previous 146-byte first-turn map and 65,536-tick C99 interval adapter, without modifying those frozen modules.

**State separation / API:**
- Observability: candidate phase from a gyroscope can fall in a missing 64-bin map cell; a request does not fabricate a column.
- Warrant: an upstream independent verifier must authenticate the same source epoch, confirm the current first revolution, and provide BOTH a calibrated gyro-phase error bound and calibrated camera-IMU timestamp error bound combined into an externally justified 16-bit angular radius. Merely reading the EvSLAM signed nominal -2.586ms Kalibr shift does NOT provide that. Default all-zero evidence returns named missing-source-epoch/clock/gyro obligations and leaves map unchanged.
- Permission: only with all four externally checked fields equal to exactly 1, a 0..511-tick inclusive radius confined to exactly one angular bin, and a nonquarantined missing reference may mg_source_firstturn_obligation return MG_OBLIGATION_ACQUIRE_COLUMN. It DOES NOT write the map. Following acquisition of actual physical 16-bit column, mg_source_capture_with_evidence delegates to the byte-identical existing mg_firstturn_capture_fine_interval and map capture. Frozen, inconsistent or filled source maps refuse work.
- No self-authentication: the source flags are CALLER assertions and can be forged. The physical bound/clock/sensor authenticity MUST be independently measured and verified upstream. Deliberately false-warrant negative control demonstrates an incorrect physical-bin claim can still cause a conditional accepted map cell.

**Original methods preserved:** firstturn_fine_capture.c Git blob 1e25217918c5011ffb08ad1d5dbed5dfac10c802; firstturn_interval_capture.c b7957be414692be82449ff4daa90751011621304; finite_partial_map.c 08b1b8da9e3420ef3d50b58cd29552c4857e6b29. New acquisition wrapper has no extra persistent data and no heap, runs on freestanding Cortex-M4 object compilation.

**Independent C99 test requirements:** Exhaustively check all 65,536 reported 16-bit phases for each radius 0,1,7,127,511,512,1023 against a mathematically separate within-bin offset oracle (458,752 configurations), without mutating the source map. Verify zeroed/invalid evidence, ambiguous bin boundaries, first-turn closure, clock and gyro missing, quarantined/seen bin, no fake column insertion, and a deliberately lying source bound. Run full pre-existing 720,896-case fine interval oracle unchanged.

**Tradeoff:** This active path skips already populated cells to reduce acquisitions, but that sacrifices changed-scene duplicate checking that a continuously observing comparator could perform. Such an observation must be independently verified in a later tracking/evidence-withdrawal stage. No claims of flight-ready absolute heading, improved physical gyro bounds, power saving or superiority over equally informed conventional acquisition. No changes to Joshua's repositories or existing PR.
