# DARK-GS-Fusion 2026 original UAV yaw-turn source admission (preregistered)

Original public published DOI [10.57745/EV12AZ](https://doi.org/10.57745/EV12AZ), dataset by NDOYE, NEGRE, RUFFIER, MARCHAND, license Etalab Open License 2.0, published 2026-03-23 at Recherche Data Gouv. Authors describe an actual UAV with RealSense compressed color/depth images, XSens IMU around 200Hz and an internal /Darknav/pose reference stream. Two rotations labelled 360 and 360_2. These are NOT event camera observations and the exact physical source of /Darknav/pose has NOT yet been established as external mocap. A noninertial pose is not automatically independent optical truth.

Freeze before actual original data read: (1) select only public deposit 360.zip for development, published 134.3MB, MD5 2b6eb3220c82ecab96dc8a4d918464ed, (2) reserve 360_2.zip, published 171.0MB, MD5 9a05e7d528241ad9a4f055170f3a710f as SECOND source. Select by original Dataverse API identity/MD5 only, not by sequence showing a favourable result. The original file ID is discovered through the public dataset JSON, not guessed. SHA256 computed on exact acquired archive. Validate ZIP names and size; extract to CI scratch only; never commit or distribute original sensor bytes. Inspect ROS2 connection/topic index without reading camera or IMU payloads; read only original publisher pose header timestamps + quaternion + position.

Predeclared physical geometry qualification: WORLD-Z yaw from independently tracked original quaternions, gyro/body xyz projections reported jointly. Require strictly monotone source pose clocks, unit quaternions, no near yaw gimbal, every 3D incremental rotation below 90deg, pose gaps <=250ms, >=2 uninterrupted directionally consistent world-Z yaw turns ignoring <=0.2deg incremental noise, >=2 body-Z signed projected turns, and >=90% SO3 travel projected on body-Z. A visible "360" label, absolute 3D travel, and one revolution are NOT sufficient. Any source-normalization/clock failure returns UNKNOWN/REJECTED, with no controls authorized.

Promotion: only a source-positive result allows a separately frozen firstturn-only fixed column matching experiment (using original compressed camera image stream and original gyro) with the publisher pose used only for offline scoring; expose source distinct 360_2 only after freezing all visual matching decisions and thresholds. In source-negative case, retain negative and report exact obstacle; do not retune axis/post-hoc reverse chronology to invent continuous spin. This source test is not itself a flying drone compass or a MathGraph advantage demonstration. The UZH/ECRot/EFRD, TOPSPIN and EvSLAM negative/positive chains remain separate.
