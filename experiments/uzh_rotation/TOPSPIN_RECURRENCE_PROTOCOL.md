# TOPSPIN v1 — source-authentic recurrence test (not camera-gyro visual compass)

**Objective:** Determine whether a one-pixel event column from a real spinning-object recording contains a time-repeating appearance cue that transfers from the first chronological half to the second, and whether the cue is ambiguous between candidate repeat intervals. Do NOT equate static event camera observing an object on a turntable with an aircraft spinning in place.

**Frozen data sources:** TOPSPIN Zenodo https://zenodo.org/records/10884694. Development `hubble-perpendicular-slow.tar.gz`, published MD5 `791716392f201526d814267155291147`, SHA256 `de27852e28ba0ceff828aeda578fb56db8cb5166599324368522cd105b379526`, [source audit #39884717443](https://github.com/metalogiclabs/mathgraph/actions/runs/39884717443): 4,059,443 real events over 59.995s, 11,088 at fixed center pixel x=640. The width 1280 and height 720 come from the original nested meta.json; metadata-based center column chosen before reading events. Reserve SOURCE-DISTINCT `switch-perpendicular-slow.tar.gz`, published MD5 `498aa6f860bd226384a60c773ee8a8a9` for one prospective transfer after freezing the method. Its contents remain unopened at this v1 freeze.

**Causal finite procedure:** window every 100ms using first event timestamp; tally 24 vertical bins × 2 polarities only at one predetermined column. Split chronologically into first and second halves. Source train mean/standard deviation on square-root event counts and whiten each window with train-only scale. Match lagged normalized histograms with conventional cosine similarity; require 40 eligible nonempty paired windows. Search lags 5–150 bins (0.5–15s), select best first-half lag (smallest lag tie-break), compare with best non-neighbor lag excluding ±2 bins. If training correlation below 0.08 or margin below 0.04, withhold unique-period authority. Freeze selection; replay on second half. Never adapt lag, features or threshold to later observations. Report validation rank against all lags **for offline evaluation only**, not for algorithmic decisions. Include an equally informed rate-only Pearson baseline with its own first-half lag and second-half evaluation; the full-descriptor matched filter is itself a conventional strong baseline. There is NO MathGraph superiority claim from a conventional ambiguity gate.

**Hard limits:** No object turn count, angular phase, gyro, external encoder, heading labels or physical-line-camera measurement. A temporal lag may represent illumination flicker, alias, harmonic or spurious recurring event structure rather than revolution. We can only state bounded reproducibility and ambiguity/UNKNOWN of real single-column events, never a heading correction, autonomous relocalization or flight readiness.

**Verification:** Independent code unit controls for exact harmonic ambiguity, sparse windows, negative counts, and later-half noninterference. Original archive checksum, source timestamps and real event totals must match before any further promotion. Holdout source must run with method and tests byte-identical.
