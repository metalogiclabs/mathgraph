# L4YAML varied PR audit experiment

The experiment supports a bounded independent verification role. It does **not** qualify MathGraph Check as a turnkey reviewer for arbitrary L4YAML PRs, and it found **no new confirmed upstream defect** in the four tool modules tested.

## Evidence and scope

The 12 newest PR snapshots visible when the cohort was frozen (#201–212) were copied to owned-fork draft PRs [#6–17](https://github.com/metalogiclabs/L4YAML/pulls?q=is%3Apr+%22Calibration+snapshot%22). Original base/head revisions are retained in `selection.json`; `cohort-summary.json` records the actual App Checks. The selection was committed before diff acquisition at [b73c7ad](https://github.com/metalogiclabs/mathgraph/commit/b73c7ad6e233c827c4372970144d831a4ca8b251).

All 12 live `@MathGraph -check` invocations completed with neutral, explicit `UNKNOWN / UNSUPPORTED_CHANGED_FILE_SCOPE`. This verifies admission behavior, **not native investigation of all 12 PRs**. The deployed controller remains `3595329c1cce8c83171eb37c32c44042d05f2b35`; production scope was not broadened.

Separately, an offline research profile executed native Lean controls and finite comparisons on pinned source from our fork. Controller: `528aa7d4d60651afab4efafb3a00425794ba56fe`. [Native run](https://github.com/metalogiclabs/mathgraph/actions/runs/41554503958). Lean: `4.35.0`; source, reference, generated-corpus and runtime identities are retained in artifacts. Execution uses containers without network or credentials. The reviewed-source boundary does not establish arbitrary-source immutability or sandbox security.

Eleven human-authored rows are retained in [fork PR #18](https://github.com/metalogiclabs/L4YAML/pull/18), fixture SHA `58e2ec714c4348e075a1da7e73beb6f70830eadf`. All 11 rows matched their labels in the revised native calibration. These are calibration observations under experiment-owner requirements, not discovered Nicolas/Devin defects or scientific judgments. Kernel acceptance remains distinct from sufficiency for an owner's claim. A missing particular proof dependency alone is not a defect.

## Review comparison and negative evidence

The acquired public records contain 19 posted candidate Devin finding threads across these 12 PRs. Formal Devin review entries exist at nine frozen heads; formal review or inline-comment records exist at 11. These counts do not score validity, recall or resolved findings. Private review visibility remains UNKNOWN. The public findings concern substantive CLI, integration, parsing and verification-gate behavior.

The corpus was constructed after examining public reviews. This is not a blind head-to-head comparison. No comparative superiority claim is supported. Newest PR #212 now has a public same-head Devin review; the older single-PR protocol's lack-of-review observation remains historical, not current evidence.

We also audited the audit implementation:

- Independent review found that sparse evidence could trust a `complete` flag and that changed failure witnesses could be mislabelled inherited. Admission now validates evidence fields and retains uncertain lineage. Regressions were observed failing before fixes.
- Another review found early UNKNOWN module results could be absent from the durable aggregate. All paths now checkpoint atomically.
- First module replay [41553903607](https://github.com/metalogiclabs/mathgraph/actions/runs/41553903607) failed on host permissions for container-owned `.olean` output. It supplied no qualified module result; ownership handling was corrected.
- The next run [41554188807](https://github.com/metalogiclabs/mathgraph/actions/runs/41554188807) reported one generator parity candidate. Investigation showed our harness compared a full generated file with Python's body-only output. The **defect inference is REJECTED**. Both-body comparison passes in the corrected run; the original failure and correction remain in lineage.

Validation: 422 existing Node tests pass, nine pre-existing skips; six existing collector tests pass; 15 research admission/persistence tests pass. No production deployment, upstream change, email or upstream review comment was made.

## Remaining consequential residual

The reliable reusable unit is a **declared obligation plus independent native replay and evidence admission**. This experiment automates replay and classification once that boundary is supplied. It does not infer and authorize the owner's intended claim automatically.

The next decisive test is a fresh multi-file fork PR checked through one reviewed repository contract, with no per-PR adapter or expected-result edits. Include explicit required consumers, assumption policy and generation obligations, and qualify both passing and failing cases before enabling that broader hosted profile. Until then, Nicolas's independent installation for arbitrary PRs remains UNKNOWN.
