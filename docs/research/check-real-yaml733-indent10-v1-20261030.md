## New causal hypothesis and independent rule

The YAML 1.2.2 standard, §8.1.1.1, formally defines the **explicit block scalar indentation indicator as a single ASCII digit 1–9**: https://yaml.org/spec/1.2.2/#8111-block-indentation-indicator . The AI-assisted PR #738 implementation changes mapping block stringifier logic to output `String(ctx.indentStep.length)` in `src/stringify/stringifyString.ts`, and `ctx.indentStep` is built as `' '.repeat(opt.indent)` for a numeric `ToStringOptions.indent`. The public option documents a numeric indentation count without an explicit maximum; PR prose says it fixes mapping values at custom indentation widths. **Hypothesis only:** an indent count 10 or greater might generate a multi-digit `|10` or `>10` indicator, causing successful stringify output to be unparseable or corrupt.
