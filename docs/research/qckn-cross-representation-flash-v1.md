## Live schedule

The target starts with only its six opaque primitives and performs complete level-by-level search.

It exhausts depths **1 through 6** before the source event arrives.

- verifier calls: **35,290**

The ordinary cold target requires depth 7 and totals:

- verifier calls: **222,808**

Only after the depth-6 frontier is exhausted does the source developmental procedure arrive.

Its six semantic roles are exhaustively compiled into the disjoint target vocabulary. The 216 adapter probes are fully charged. The scheduler then evaluates only newly enabled programs containing the compiled `XFER` capability; all target-only programs already paid for remain cached facts.

## Pass gates

The run passes only if:

1. source and target surface vocabularies are disjoint;
2. target depths 1–6 are exhaustively searched and contain no solution;
3. cold prefix is exactly 35,290 verifier calls;
4. full cold is exactly 222,808;
5. upfront transfer is exactly 320;
6. live Flash is exactly 35,602;
7. only 312 post-arrival calls are required;
8. exactly 187,206 cold calls are avoided;
9. raw history and ablation restore cold;
10. answer memory alone restores cold;
11. the redundant sham costs more than cold;
12. all terminal arms still produce an admitted correct target procedure.

## Claim boundary

A pass earns a bounded result:

> A verified developmental procedure can arrive after an opaque foreign target has already exhausted six levels of cold search, be exhaustively behaviorally compiled into that disjoint representation, and cancel most of the target's remaining combinatorial search. Raw history, answer memory, exact ablation, and a behaviorally compilable but redundant sham do not reproduce the effect.

This is not learned adapter discovery, natural-domain transfer, unrestricted representation invention, universal cross-domain transfer, or unbounded self-improvement.
