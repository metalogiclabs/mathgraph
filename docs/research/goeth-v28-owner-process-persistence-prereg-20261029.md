## Preregistered decisive four new test roots

1. **Actual OWNER OS-process SIGKILL after native VALID:** Native Geth is a still-running parent-test service with both forks imported and B epoch2 canonical. Owner process is initialized at observed B2, then a newly launched **lower-privilege gateway** submits genuine synthetic signed B epoch3. Owner writes PREPARED3, executes and observes real native `VALID` and B canonical, emits exact after-effect-before-journal marker and blocks. Parent sends OS `SIGKILL`, checks process exit signal, gateway sees ambiguous completion. Owner state remains PREPARED3. A newly launched owner OS process reopens the **same protected key and durable journal**; new lower-privilege gateway calls read and submit B4 and gets `ABSTAIN_IN_DOUBT`. Owner-native exact-head/final reconciles OBSERVED3; B2 stale denied; a new signed B4 is forwarded to real native Engine `VALID`. This is **owner process** restart; Geth stays running.
2. **OS-level trust separation and direct native denial for the gateway:** owner key, owner state and Geth JWT are all unreadable to OS user `nobody`. A direct HTTP Engine call with no JWT returns HTTP `401`. Lower-privilege gateway can still fetch and independently verify a challenge-bound latest owner receipt. This is not proof privileged runner/root cannot access secrets.
3. **Mandatory privileged OWNER checkpoint rollback negative:** after native B3 and clean owner SIGKILL, an actor in the owner/runner privilege domain rewrites `owner.state` to its valid older B2 copy *without changing the Ed25519 private key*. A new owner process signs fresh B2 and accepts replay of previously executed synthetic B3, again returning native `VALID` (same canonical B head). This demonstrates that a locally persisted signed owner checkpoint is **NOT non-rewindable** against its own authority-domain actor. Do **not** count this as a chain rewrite.
4. **Malformed owner store negative:** a corrupted protected state file prevents owner service startup and cannot silently reset the epoch, with native B state unchanged.
