# QCKN Verified Bridge Genesis V1

## Question

Can a cross-domain bridge be **discovered rather than supplied** after both the source event and destination work already exist?

V1 deliberately chooses a finite setting with a complete interface authority: the previously qualified cross-representation developmental procedure has six source semantic roles, while the destination exposes six opaque operations with disjoint token names.

The bridge learner is not given the source-to-target role mapping.

## Causal order

The destination target starts first.

It exhausts cold search through depth 6:

**35,290 verifier calls**

and remains unsolved.

Then the source developmental event is admitted into the bus.

At this point there is **no bridge** and therefore:

**0 cross-domain edges**.

Only then does bridge genesis begin.

## Candidate destination portfolio

The learner is given three opaque interface candidates:

1. **opaque-exact-v1** — the true foreign interface;
2. **opaque-mismatch-v1** — one operation's complete signature is corrupted;
3. **opaque-ambiguous-v1** — one source behavior has two surface realizers while another disappears.

No target is privileged by name.

## Discovery

For every source role and every target operation, the learner evaluates the complete six-case behavioral interface.

For one target interface this is:

6 source roles × 6 target operations × 6 cases = **216 behavioral probes**.

The three-target portfolio therefore costs **648 discovery probes**.

A candidate is not admitted merely because it looks unique under search. It then undergoes an independent complete attack:

- each mapped pair must agree on all six probes;
- each of the 30 nonmapped source/target pairs must have at least one separating probe.

The exhaustive attack costs another **216 probes**.

Total bridge authority:

**864 behavioral probes**.

Only `opaque-exact-v1` survives.

## Learned bridge

The resulting certificate contains:

- source interface fingerprint;
- target interface fingerprint;
- unique six-role bijection;
- complete probe basis;
- independent attack result.

Only after that certificate exists is a `BridgeCertificate` admitted into the GlobalFlashBus.

Because the source event was already present, bridge admission materializes the cross-domain edge immediately.

## Live target effect

The target does not repay bridge authority.

The discovered role map compiles the previously learned source procedure into the opaque target representation.

The target had already paid:

**35,290 calls**

After bridge admission it needs only:

**96 additional target verifier calls**.

Target total:

**35,386**

versus cold:

**222,808**

So the learned bridge removes:

**187,422 opaque target verifier calls**.

Bridge authority remains a separate typed cost:

**864 bridge.behavior_probes**.

This is intentionally not added to target verifier calls.

## Controls

### WITHHOLD

Bridge discovery succeeds, but the certificate is not admitted into the bus.

Result: target stays cold at **222,808**.

### INCOMPLETE

The learner receives only the first behavioral probe.

The interface is ambiguous and the probe basis is incomplete.

Result: no bridge admission, no edge, target stays cold.

### NO_EXACT_TARGET

The candidate portfolio contains only mismatch and ambiguous interfaces.

Result: no bridge.

### AMBIGUOUS_DESTINATION

Two opaque target identities expose the same exact interface.

Each individually supports a behavioral bijection, but destination identity is not unique.

Result: bridge genesis refuses admission.

### RESTART

After the source event is admitted but before bridge discovery, the runtime snapshot is canonicalized and restored. Bridge discovery then reruns.

The same certificate, bus edge, and target result must be produced.

## Pass conditions

V1 passes only if:

1. the destination has already paid 35,290 cold calls before bridge search;
2. the source event initially has zero cross-domain edges;
3. source and target surface names are disjoint;
4. exactly one target interface survives complete discovery and attack;
5. all six role mappings are unique;
6. both decoy interfaces are rejected;
7. bridge admission creates exactly one bus edge;
8. the live target finishes at 35,386 calls with only 96 post-bridge calls;
9. the bridge search is charged all 864 probes;
10. withholding the certificate restores the cold target;
11. incomplete evidence cannot admit a bridge;
12. absent exact targets cannot admit a bridge;
13. ambiguous destinations cannot admit a bridge;
14. restart reproduces the exact bridge certificate and target outcome.

## Claim boundary

A pass establishes bounded **verified bridge genesis** over a declared finite candidate-interface portfolio and a complete finite behavioral probe basis.

It does not establish open-ended semantic analogy discovery, natural-language ontology matching, autonomous invention of probe languages, or arbitrary transfer between unrelated natural domains.
