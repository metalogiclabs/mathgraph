# QCKN Heterogeneous Global Flash V1

**Status:** executable preregistered causal probe  
**Host:** `metalogiclabs/mathgraph`  
**Branch:** `qckn-heterogeneous-global-flash-v1`

## Question

Can a verified capability acquired in one domain arrive **after another domain has already begun cold search**, then immediately reduce that live target's remaining developmental cost, while unrelated live domains remain unchanged unless they have their own verified adapters?

This is the first heterogeneous Global Flash gate. It is deliberately narrower than universal cross-domain transfer.

## Live scheduling change

In V1 the target is allowed to begin cold.

Timeline:

1. the finite embodied target starts with the full 256-operator candidate universe;
2. it pays exactly one real target intervention and the associated cold operator evaluations;
3. only then does the ARC-like source capability become available;
4. the shared graph recompiles the target's active candidate family using the verified relational adapter;
5. the target continues under the same confirmation rule as the qualified transfer experiment.

Thus Flash is neither an upfront guard nor ordinary warm start.

## Arms

### COLD

No source capability reaches the target.

Expected developmental cost: **518**.

### UPFRONT

The verified source capability is available before target work starts.

Expected developmental cost: **5**.

This is a lower-bound control, not the Flash treatment.

### FLASH

The target first pays one cold intervention. The verified capability then arrives and re-closes the live target.

Expected developmental cost: **261**.

### RAW_SHARED

Source history is visible but no executable capability is compiled into the target present.

Expected developmental cost: **518**.

### ABLATION

The valid capability is removed at the arrival event.

Expected developmental cost: **518**.

### SHAM

A same-schema majority capability arrives after one cold intervention. It must be rejected and the target must recover via cold fallback.

Expected developmental cost: **789** and `transferred_rejected = true`.

## Heterogeneous spectators

Four additional obligations are represented as already-live graph nodes:

- QCKN typed finite-map acquisition;
- Collatz bank-order policy frontier;
- P-vs-NP circuit construction-state repair;
- LeanEval consumer continuation.

The ARC-like source capability is **not** licensed to act on any of them.

Their evidence contracts use different effects and/or authority boundaries. No generic “everything is transferable” adapter is assumed.

The run fails if any spectator is discharged or modified merely because it shares the global runtime.

## Pass gates

The experiment passes only if:

1. all six target arms recover the exact target operator;
2. the target has already paid cold work before Flash arrival;
3. COLD = 518;
4. UPFRONT = 5;
5. FLASH = 261;
6. FLASH < COLD;
7. UPFRONT < FLASH;
8. RAW_SHARED = COLD;
9. ABLATION = COLD;
10. SHAM is rejected;
11. SHAM = 789;
12. every unlicensed heterogeneous spectator remains LIVE;
13. the pinned source run and artifact still match the frozen identifiers.

## Claim boundary

A pass warrants:

> Within the pinned finite relational family, a capability acquired in an ARC-like symbolic domain can arrive after a finite embodied target has begun cold development and causally reduce the target's remaining developmental cost; raw history and exact ablation do not reproduce the effect, a sham capability is rejected, and unrelated live obligations remain unchanged without verified adapters.

It does **not** establish:

- ARC-AGI -> physical robotics transfer;
- semantic transfer into Collatz, P-vs-NP, Lean, or arbitrary mathematics;
- universal cross-domain capability transport;
- asynchronous distributed consistency;
- open-ended self-improvement;
- that the source discovery cost is free.

Source discovery work is reported separately from target developmental cost, exactly as in the qualified source experiment.
