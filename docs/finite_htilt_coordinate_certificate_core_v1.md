# Finite H-Tilt Coordinate Certificate Core v1

This promotes `RawCoordinateDominanceCertificate` into `HTilt.CoordinateChecklist`. It is the first reusable finite-coordinate continuation certificate kernel in the tower.

The certificate bundles raw residual evidence, raw strict-gap evidence, and scalar side conditions. Its core methods build `CoordinateEnvelopeChecklist` and prove shifted dominance. A concrete singleton fixture verifies downstream import and use.

This remains pre-spectral finite-coordinate real/list algebra. It does not prove eigenvalues, matrix-spectrum correspondence, extraction, Perron-Frobenius, convergence, or empirical and interpretive claims.
