# L4YAML observation-ceiling audit — bounded implementation plan

## Specification

For a frozen observation `alpha` and a protected target `Phi`, an admitted pair
with equal `alpha` and unequal `Phi` refutes any universal decision procedure
that relies *only* on `alpha`. A finite set without a collision cannot establish
universal sufficiency. Preserve independent source identity as a distinct axis.

The frozen L4YAML `parseYaml` accepts `#a` and `#\u0001`; the first passes the
necessary `NoRawSOH` source requirement and the second violates it. This is a
source-pinned obstruction to an acceptance-iff-normative-language theorem for
that parser revision, **not** a full YAML language model. The original qualified
Lean proof is the evidence authority; this JavaScript consumer checks only the
declared table and its independently supplied authority.

## Global constraints

- Do not change the production YAML parser or upstream JPL repository.
- Do not give the MathGraph app a universal positive proof badge or merge power.
- Do not derive trust from a producer-authored table or its own hash.
- Keep the complete Group 7.7 exact language and repair UNKNOWN.

## Review focus

- Provenance-only source collisions must not be mislabeled as semantic no-go.
- A bounded positive observation must not imply universal target equality.
- An in-band table hash must not serve as independent qualification.
- Actual accepted source with an illegal raw character must not be mistaken
  for successful proof of the complete normative YAML grammar.
