# Finite H-Tilt Coordinate Raw Evidence Core v1

The reusable `HTilt.CoordinateChecklist` module now exposes the raw residual/gap evidence adapters, checklist constructor, and shifted-dominance theorem.

The smoke fixture imports only the core module and calls both bundled-checklist and dominance declarations.

## Boundary

This remains pre-spectral finite-coordinate real/list algebra. Coordinates are not proved to be eigenvalues or a matrix spectrum; no Perron-root, Perron-Frobenius, irreducibility, convergence, or empirical claim is made.
