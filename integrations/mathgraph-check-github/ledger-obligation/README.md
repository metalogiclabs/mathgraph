# Bounded ledger gate qualification

This opt-in owned-fork experiment connects a native obligation replay to a MathGraph Check evidence adapter and advisory GitHub Check. It is not enabled in the production mention controller.

The frozen obligation is that an empty Python ledger must reject the seven selected Bash fixtures exactly when unlisted inline Python executes. The independent oracle executes the fixture and observes a marker. A second replay runs the actual native gate over the pinned repository inventory: clean, direct added call, option-prefixed added call, withdrawal. The same Lean regression file is checked before repair, after repair and after withdrawal. It includes authorized inline/script calls, covered module runs, version/help probes, quoted data and unsupported invocation controls.

The receipt consumer requires the watched source, verifier commit, run and complete original/repair/withdrawal protocol. Missing, stale, malformed or unauthenticated evidence is UNKNOWN. It reports PASS only for this finite qualification protocol, with original FAIL, repair PASS and withdrawal FAIL. This is a replay of deliberately selected known controls, not a prospective discovery benchmark or evidence of superiority over other reviewers.

`replay.py` produces source identities, native logs and a checksummed receipt in an unprivileged trusted-push job. `qualify.mjs` verifies those bytes and feeds the pure adapter. The separate publisher revalidates the same-run artifact before creating a neutral advisory Check. Its GitHub identity is github-actions, not the registered MathGraph Check App. The carrier commit belongs to MathGraph; the watched source belongs to the L4YAML fork. The Check explicitly distinguishes them.

The repair handles supported interpreter options before classifying execution targets, retains the full ledger command key and refuses unsupported recognized interpreter invocations. It does not prove general shell inventory completeness, alter interpreter-name recognition, validate the full L4YAML library, or authorize an upstream merge.

Run adapter tests with `node --test integrations/mathgraph-check-github/ledger-obligation/*.test.mjs`. The isolated qualification workflow installs Lean 4.35.0 and runs the native protocol. No LLM, App token or upstream write is involved.
