# Frozen six-case discovery pilot

Two isolated adaptive investigators receive the same six external cases, source
extracts, reference tools and logged access budgets. One is instructed to use
the existing MathGraph warrant graph and boundary records; the conventional
investigator may use any strong conventional audit, including dependency
tracking, caches and retained results. Both may construct verification adapters.
Neither receives outcome labels, the other's outputs or the parent transcript.

Freeze the protocol, prompts, selector and broker publicly before cloning or
selecting case content. Select two records per domain by a fixed SHA256 ranking:
official YAML fixtures, NASA FRET requirements excluding prior cases, and
externally authored mathematical satisfiability problems. Read source bytes
directly from regular-file blobs in pinned Git trees. The selector keeps the
full eligibility roster, original source material and hidden status labels for
later adjudication, while printing only opaque IDs and counts.

Two of the six cases receive an explicit source-authority withdrawal context
intervention. Score these controls separately from the four current-source
cases. They are not newly discovered natural source defects. A source byte
string can remain visible while authority for a current conclusion is absent.

Every research read, write and execution goes through the same broker. There
are 24 credits per case and 12 shared credits. Reads, lists, writes and final
locks cost1; executions cost4. Failures count. The broker preserves request
payloads, write versions, complete stdout/stderr and pre/post execution file
snapshots, uses process-group timeout cleanup, and prevents case aliases from
resetting budgets. Invocation records measure actions, bytes, generated code
and wall time. This is procedural investigator isolation on a shared host,
not a hardened sandbox against hostile code.

Both final result files lock before operator inspection or adjudication. A
third isolated reviewer checks original sources, identities, actual executions,
scope, witnesses and missing obligations. Investigator UNKNOWN, ground-truth
uncertainty and deliberate withdrawal controls are different scoring outcomes.
The complete frozen rubric is `adjudication_prompt.txt`.

This is one paired pilot with the same inherited model/settings, not a general
or statistically established architectural comparison. Exact model weights,
sampling seeds, billing tokens and monetary cost are unavailable. Preserve
these costs as UNKNOWN. Common setup, corpus acquisition, orchestration and
adjudication costs must be reported separately; do not hide adapter creation,
failed attempts, cache differences or a tie.

The holdout boundary is operational selection after frozen instructions. It
does not establish absence of pretraining exposure. The FRET repository was
seen in previous research; explicitly exposed case families are excluded.
Mathematics here means declared satisfiability problems, not general prose
interpretation or arbitrary Lean correspondence. No production source changes
or terminal-form kernel admissions are part of this research study.

Before selection, run the synthetic broker/selector checks:

```bash
PYTHONPATH=/path/to/deps python3 -m pytest research/semantic_discovery_six/test_broker.py research/semantic_discovery_six/test_selection.py -q
```

After obtaining the three pinned repositories under a source directory named
`yaml`, `aerospace`, and `mathematics`, execute:

```bash
python3 research/semantic_discovery_six/select_cases.py --sources /path/to/sources --out /path/to/new-trial --freeze PUBLIC_FREEZE_COMMIT
```
