## Frozen source-independent method (check-only)
Given two independently executed same-domain programs with a stated contract:
1. Read official READMEs only to locate original build/test entrypoints. Run exact
   original native checks of the pinned Lean spec and Rust implementation, not
   a modified mock, and preserve complete exit codes and logs.
2. Using names/metadata only, identify the first shared, *explicitly claimed*
   evaluator correspondence conformance suite or reference fixture the authors
   provide. Ordering is normalized lexical filepath ascending; ties resolved
   by exact path. The fixture must name both execution surfaces and expected
   Cedar policy authorization outcome. Do not infer relationship from names alone.
3. If no such native pair exists, STOP UNKNOWN_NO_SOURCE_GROUNDED_COMMON_ORACLE.
   Do not create a new supposed author-intent contract from lexical similarity.
4. If a shared author-declared corpus is found, execute its FIRST lexicographic
   true dual-executor case in both exact original source programs; record complete
   program/request/response, revisions, hashes, result and normatively declared
   meaning. On unsupported API or unresolved reference STOP UNKNOWN_INAPPLICABLE.
5. Predeclared separate matched control: explicit independently authored
   rulebook sees the same fixture and outputs, using exact equality of typed
   permit/deny/error outcomes and no special Cedar source knowledge. No claim
   of human expert performance, autonomous observer invention or superiority.
6. Only if both real native outputs and the required author-declared semantics
   are authenticated, wrap evidence in unchanged MathGraph warrant resolver:
   (a) exact finite same/different result; (b) logical source/denotation and
   implementation receipt withdrawal; (c) preserved unrelated original test
   receipt; (d) restoration. A green test alone is never source fidelity.
7. Physical and independently signed source authority, an inductive/semantic
   proof of correspondence, and the universal Lean proof-of-proof law remain
   out of scope. No source changes to upstream repos or main MathGraph branch.
