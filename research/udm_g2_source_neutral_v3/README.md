# UDM G2 source-neutral native observer adapter — research only

This is a source-neutral extension of the [previous G2 observer pilot](../udm_g2_observer_v1). It is *not* a G3 autonomous operator-genesis theorem or a production MathGraph Check release.

A model may propose two equally informed Go tests (discovery-oriented and direct baseline) from an immutable upstream original-author RED/GREEN residual, original base implementation, and exact source identity. It must not see the author-test body, contributor fix, PR title or patch. Independent Go execution has no model API key. Candidate tests require AST admission, exact source package match, named assertion failure on base, pass on head, physical withdrawal and restoration. All non-admission and non-executed states remain scoped UNKNOWN.

The apparatus uses a small allowlist, **not** a trusted sandbox. Never execute arbitrary model-generated code with secrets or elevated privileges. Its native qualification is about a finite test witness, not genuine owner authorization. Preserve the original V45 cohort and other frozen research pools. This adapter is exercised on a known prior source before a separate source-distinct experiment, and any post-outcome retuning must be labelled POST-HOC.
