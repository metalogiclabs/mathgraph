## Exact declared semantic scope

Input is a **completely specified, finite, deterministic state/test system**:

1. A stable finite state list and **declared protected future signature** `p(state)`. This signature must independently cover every real consequence the user says must be protected; checking a single hidden bit does not certify arbitrary physical future preservation.
2. A frozen finite set of typed, fully defined state transformations `f: X→X`, each with positive cost, and a set of terminal pure observations `r: X→O` with positive cost. **Effectful readout dynamics beyond the listed primitive transformations are outside V1.**
3. A separate frozen permission snapshot grants names of physically admissible operations/readouts. An operation can be syntactically present but not granted. An action is V1-safe only if it preserves the declared protected signature for **every** state at **every primitive step**; a net-safe but transiently harmful trajectory is intentionally excluded.
4. The existing observation set gives the prior equivalence kernel. A new desired partition is intersected with this original kernel, so an old empirical distinction is never silently merged or erased.

The mathematical task is to synthesize a **minimum-total-cost collection of observable program instances** whose joint kernel, combined with the existing observations, equals the desired quotient. Extra, unrequested distinctions within target-equivalent pairs are not silently considered an exact target quotient.

## Completeness and evidence boundary

- Finite transformation closure is Dijkstra over all reachable state maps, **without a search-depth cap**. It is complete only for the supplied finite grammar. Source-provided semantic tables and permission are **assumptions**, not automatically inferred from prose.
- Every reachable final readout profile is reduced to a least-cost program; exact weighted set cover finds a least-cost observation basis. All primitive costs are positive; ties use a deterministic lexical policy.
- If the best admissible profile family cannot cover a desired state separation, issue `UNREALIZABLE_IN_COMPLETE_DECLARED_FINITE_GRAMMAR` plus an explicit missing pair and the closed transformation census. **This is NOT a universal impossibility theorem.** If the missing separator exists in the supplied grammar but is denied by the grant snapshot, issue `MISSING_PERMISSION_FOR_EXISTING_SAFE_OPERATOR` rather than claiming new sensor invention.
- If even full hypothetical grants over source-provided safe primitives cannot separate, issue `NEEDS_NEW_OBSERVATION_TYPE_OR_REVISED_TARGET` as a **pure missing-capability specification**, not permission to invent physical access.
- If finite closure hits the declared capacity, stop `FINITE_CLOSURE_RESOURCE_BOUND` and **do not issue an impossibility certificate**.
