# Evidence challenge against authentic source-generated observations

These are **synthetic mutations of copied observation records**, not genuine
defects in Qwen-generated Rust, source C, or the published dataset.

The comparator must still catch or reject every altered result even when
the perpetrator updates the receipt digest. Eight controls include:
Boolean false-result flip; wrong signed absence sentinel; wrong length
sentinel; corrupted absence result in the implication-only family that
MathGraph's bounded source extractor abstained on; corrupted C result;
missing observation; reordered observations; and falsified source blob.

The comparator has independent source-understanding rules and can review
all five contracts, versus four currently supported by the MathGraph
source-only rule extractor. This is not a superiority benchmark in which
MathGraph wins. The release decision remains bounded by the authentic
requirements and evidence, not the induced mutations.
